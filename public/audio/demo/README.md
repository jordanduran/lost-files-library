# Synthetic preview fixtures

Eight original, programmatically synthesized 16-second WAV loops. No third-party
recordings or samples are used. These are public development fixtures, not the
actual beats offered for sale. All catalog preview buttons play these files.

Regenerate with `npm run fixtures:audio`. Each file is mono 22,050 Hz, 16-bit PCM.
Use these to test playback, seeking, mute, volume, and track changes. They can
also be uploaded to private storage later to test purchased-file delivery.
Never place actual paid audio in this public directory.
